Floodgate: personal classification on River

273 browsing labels + River LoRA: held-out agreement 66–69% → 77–80% in 8 steps.

Team: cyu60, quachphu, TriNguyen1110, AdityaGaur77, atilavahedian · Code: github.com/cyu60/floodgate

The classifier

Yes/No logprobs → calibrated decisions

Sample one token, top-20 logprobs; fit temperature T. The gap matches Open-Jev's initial head (lm_head[Yes] − lm_head[No]) at step 0.

score = logprob("Yes") − logprob("No") at the first answer token
P(yes) = sigmoid(score / T)

The training run

8 steps · about 2.5 minutes · no local GPU

Thinking off; prompt weight 0; train only the answer token. Soft label p → Yes row weighted p + No row weighted 1 − p.

Base modelQwen/Qwen3.6-35B-A3B-FP8, frozen
AdapterLoRA rank 8: attention + MLP; train_unembed=True
Losscross_entropy
Schedule208 × 3 = 624 rows; 8 steps; 78 rows/step; lr 2e-4; grad clip 1.0
Wall time149 s

client  = river.Client(api_key=RIVER_API_KEY)
session = client.session(project="floodgate-personal-v1")
base    = session.sample(prompts, base_model=BASE, max_tokens=1, logprobs=20)
model   = session.create_model(BASE, river.LoraConfig(rank=8, train_unembed=True))
model.train_step(rows, lr=2e-4, loss_fn="cross_entropy", grad_clip_norm=1.0)  # × 8
mine    = model.sample(prompts, max_tokens=1, logprobs=20)
ckpt    = model.save_weights("floodgate-personal-v1", mode="inference")
serve   = session.sample(prompts, base_model=BASE, checkpoint=ckpt.path, max_tokens=1, logprobs=20)
